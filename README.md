# 🌡️ Smart Temperature Control System using Arduino UNO & DHT11

## 📌 Overview

This project demonstrates a Smart IoT Automation System using an Arduino UNO and DHT11 Temperature Sensor. The Arduino continuously monitors the ambient temperature and automatically turns ON an LED whenever the temperature exceeds a predefined threshold.

Developed as **Task 3** of the Embedded Systems & IoT Internship.

---

## 🚀 Features

- Real-time temperature monitoring
- Smart automation using IF/ELSE logic
- Automatic LED alert
- Serial Monitor feedback
- Wokwi simulation

---

## 🛠 Components

- Arduino UNO
- DHT11 Temperature Sensor
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires

---

## 🔌 Connections

| Component | Arduino Pin |
|-----------|-------------|
| DHT11 VCC | 5V |
| DHT11 DATA | D2 |
| DHT11 GND | GND |
| LED (+) | D13 |
| LED (-) | GND |

---

## ⚙️ Automation Logic

IF Temperature > 30°C

→ LED ON

ELSE

→ LED OFF
